# 记一笔 — 个人财务记账 PWA

> AI 智能分析 · 加密存储 · 离线可用

一个功能完整的个人财务记账 Progressive Web App，支持多用户、多币种、Google Drive 云端同步、数据加密、图表统计分析、AI 数据分析等特性。

---

## 技术栈

- **前端**: 原生 JavaScript + Bootstrap 5.3 暗色主题
- **图表**: Chart.js
- **加密**: CryptoJS（AES 加密数据文件）
- **离线**: Service Worker（Cache First / Stale While Revalidate 策略）
- **云端**: Google Apps Script (GAS) + Google Drive

## 版本号规则

- **新功能** → 版本号 **+0.1**（如 v2.2.7 → v2.3.0）
- **Bug 修复** → 版本号 **+0.0.1**（如 v2.2.7 → v2.2.8）
- 版本号出现在以下位置，更新时需同步修改：

  2. [index.html:1347](test/index.html#L1347) — 底部版本标注
